Política de privacidad

Mission Dashboard · vigente desde el 25 de septiembre de 2026

Mission Dashboard es un tablero privado de hábitos, agenda, salud y finanzas. Esta página explica qué datos guarda esta instalación y cómo usa los datos de Google. El acceso al tablero pide usuario y contraseña. Publicar esta página no abre el registro.

Cuenta

Guardamos el nombre de usuario, una contraseña hasheada, el plan y las preferencias de la cuenta. Las cuentas nuevas las crea un administrador. No hay registro público.

Datos que cargas en la app

Lo que escribes en las áreas (hábitos, ritual, finanzas, salud, agenda, notas y archivos que subes) queda asociado a tu usuario en la base de datos de esta instalación.

Datos de Google

Si conectas Google, pedimos permiso solo para:

  • Google Calendar: leer y escribir eventos del calendario principal, para mostrarlos y sincronizarlos con el planificador.
  • Google Fit: leer sueño, actividad, pasos, calorías, frecuencia cardíaca y medidas corporales, para el área de salud.

El token de acceso se guarda por usuario en la base de datos y se usa únicamente para esas funciones, dentro de tu sesión. No vendemos esos datos, no los usamos para publicidad y no los compartimos con anunciantes. Puedes revocar el acceso desde tu cuenta de Google. Si el token deja de servir, la app te pide volver a vincular.

El uso de los datos recibidos de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Asistente

Si usas el asistente y marcas calendario, salud u otra área, el texto necesario para esa consulta se envía al proveedor de IA (Groq) para armar la respuesta. Si no marcas esa casilla, esa área no entra en la consulta.

Pagos y Telegram

Si contratas un plan, el cobro lo procesa Stripe o Lemon Squeezy. Ellos reciben los datos del pago; esta app guarda el estado de la suscripción. Si vinculas Telegram, guardamos el identificador de chat para enviarte avisos de tu cuenta.

Dónde está alojado

La aplicación corre en Railway y la base de datos en Turso. Esos proveedores almacenan los datos para prestar el servicio.
